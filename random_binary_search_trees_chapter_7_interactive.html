§7.1 Random BST

Insertion order changes the shape

Inserting sorted keys into an ordinary unbalanced BST produces a chain. A uniformly random permutation gives expected logarithmic search paths. That expectation averages over permutations, not over the searched key; individual random trees can still be tall.

§7.2 Treap

One tree, two properties

For every node, left key < parent key < right key, and parent priority < child priority. Insertion first adds a BST leaf, then rotates it upward until its priority is in the correct place. Deletion rotates a target downward to a leaf, then unlinks it. Random, unique priorities give expected O(log n) operation time.
