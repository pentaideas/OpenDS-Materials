Chapter 1 distinction

Interface ≠ implementation

The interface defines operations and expected results. Chapter 2 implements List behavior with arrays; Chapter 3 uses pointers; Chapters 4–6 implement sets with different search structures. The same abstract operation can have different time and space costs.

Mathematical background

Worst case, expectation, and correctness

Big-O describes how a resource grows asymptotically, not exact wall-clock time. Expected time averages over a specified probability distribution. Correctness requires that the implementation maintain its invariants and return values satisfying the interface contract.
