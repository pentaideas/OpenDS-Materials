§9.1 · 2–4 tree intuition

What does red represent?

Contract every red node into its black parent. A black node with no red children represents a 2-node, with one red child a 3-node, and with two red children a 4-node. The resulting 2–4 tree has every external leaf at the same depth.

§9.2 · What must hold?

Three tree invariants

Black height: every root-to-nil path has the same number of black nodes. No red edge: a red node never has a red child. Left-leaning: a red right child requires a red left child too. These properties hold after each completed operation; intermediate repair steps can violate them temporarily.
