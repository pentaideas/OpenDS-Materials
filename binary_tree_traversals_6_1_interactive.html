Idea
The traversal visits every node once.
Annotated pseudocodepreorder(u)
Key idea. Moving visit(u) before, between, or after the recursive calls gives preorder, inorder, or postorder. All three explore the left subtree before the right subtree.
Compare all orders

Same tree, different sequence

All four sequences contain exactly the same nodes. Only the order changes. The parent-pointer first-arrival order matches preorder.

Note: Unlike a binary search tree, a general binary tree does not have to store ordered keys. Inorder is sorted only if the BST ordering invariant holds.
Time and auxiliary space

Every traversal takes O(n) time

Space depends on how the traversal remembers where to go next. Height h counts edges; maximum width w counts nodes on a level.
