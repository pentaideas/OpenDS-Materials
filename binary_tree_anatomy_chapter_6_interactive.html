Core definitions

Depth, height and level are different

Depth(u)Number of edges from the root to u. Root depth = 0.
Height(u)Longest downward path from u to a leaf, in edges. Leaf height = 0.
Tree heightHeight of the root, equal to the greatest node depth.
Out-degreeNumber of actual children: 0, 1, or 2. Different from undirected graph degree.

We use proper ancestor/descendant for relationships excluding the node itself. The subtree rooted at u includes u. In Morin’s path-based terminology, a node may also be considered its own ancestor/descendant.

Structure and nil pointers

Real nodes vs. external nodes

A node stores left, right, and parent references. Missing references are nil. Enable Show nil / external children to draw missing child links as small circles.

For every nonempty binary tree with n real nodes, there are n − 1 edges between real nodes and n + 1 missing child links (external placeholders). A leaf is a real node with no real children. A node with at least one real child is internal.
